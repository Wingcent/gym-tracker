Gym Tracker

Just a simple workout tracking website I'm building while learning web development.

This is one of my first personal coding projects. My goal is to improve my programming skills by building real applications and understanding how everything works.

About the Project

Gym Tracker allows users to record exercises, weights, and repetitions to keep track of their workouts.
I'm continuing to improve this project as I learn more about HTML, CSS, and JavaScript.

Things like
HTML: Creating the structure of a webpage, including forms, inputs, and buttons.
CSS: Styling the website with colors, layouts, spacing, and a dark theme.
JavaScript: Making the website interactive, handling user input, working with arrays and objects, and saving workout data.
Git & GitHub: Tracking changes, committing code, and managing my project.

Current Features
Log exercises with weights and repetitions
View workout history
Delete individual workouts
Clear workout history
Save workout data using browser localStorage
Record the date of new workouts

Future Improvements
Track multiple sets per exercise
Edit existing workouts
Organize workouts by training day
Track personal records (PRs)
Display strength progress charts
Improve the mobile experience
Add user accounts and a database

What I'm Learning

Through this project, I'm practicing: Writing and organizing code Connecting HTML elements to JavaScript Using variables, functions, arrays, and objectsUpdating webpage content dynamically Debugging and testing features Using Git to track development progress

How to Run
Clone this repository or download the project files.
Open the gym-tracker folder.
Open index.html in a web browser.
Start logging workouts!
